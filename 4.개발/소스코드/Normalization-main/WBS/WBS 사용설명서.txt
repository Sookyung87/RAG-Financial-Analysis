사용법 :

1. 편집 사용을 누른다.
2. 새로운 칸을 생성해야 할 경우 맨 왼쪽 열 번호 우클릭 -> 삽입
3. 양식에 맞게 작성한다
3-1. 작업 : 무엇을 작업할 것인지 작성한다.
3-2. 계획 시작 주차 : 작업을 시작할 주차를 작성한다. (ex: 2주차일 경우 2) 
3-3. 계획 소요 시간 : 몇주동안 작업할 것인지 작성한다. (ex: 1~7일동안 작업 시 1, 8~14일동안 작업 시 2)
3-4. 실제 시작 주차 : 실제로 작업을 시작한 주차를 작성한다.
3-5. 실제 소요 시간 : 몇주동안 작업하고 있는지 작성한다. 작업이 끝난 후 작성하는 게 아닌 작업 중에도 매주 업데이트 해줘야 한다.
3-6. 산출물 : 작업한 후 나온 결과물 파일 이름을 작성한다.
3-7. 완료율 : 작업 완료율을 표시한다.


작업 계획 시작 주차 기준으로 나열하는 방법!
1. 나열할 그룹이 속한 맨 왼쪽 열 번호를 드래그
2. 위에 데이터 -> 정렬 클릭
3. 정렬기준 : 열 F / 값 / 오름차순 설정 후 확인 클릭

오류 발생시 정찬우에게 문의
